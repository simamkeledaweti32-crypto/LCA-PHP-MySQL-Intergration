# AfriStaff

A full-stack PHP and MySQL web application for managing staff records. This project implements full CRUD functionality: Create, Read, Update, and Delete staff members.

## Description
AfriStaff is a simple HR directory system built for managing employee records. Admins can add new staff, view all staff, edit staff details, and delete staff records. The backend is built with PHP and MySQL using XAMPP.

## Tech Stack
- **PHP**: Backend logic and CRUD operations
- **MySQL**: Database to store staff records
- **XAMPP**: Local server environment with Apache and MySQL
- **phpMyAdmin**: Database management
